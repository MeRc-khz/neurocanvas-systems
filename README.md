# NeuroCanvas v2 — Visual HTML Editor

A visual HTML WYSIWYG editor with 2D infinite board and 3D project galaxy.
Connects to remote knowledge bases via FTP, SCP, or API.

## Features
- **2D Board** — Infinite canvas with page thumbnails
- **WYSIWYG Editor** — Drag-drop text, audio, video, tables, shapes
- **3D Galaxy** — Three.js project visualization with HTML thumbnails
- **Remote Sync** — Import from FTP/SCP/API endpoints
- **Project Management** — Create, organize, and navigate projects

## Stack
- Frontend: Pure Canvas 2D + Three.js (no framework)
- Backend: Node.js/Express API
- Port: API 3004, Frontend 3005

## Access
- `https://admin.game4real.us/nc/` — NeuroCanvas v2
- `https://admin.game4real.us/nc-api/` — API

## Keyboard Shortcuts
- V = Select, T = Text, I = Image, A = Audio, M = Video, B = Table, S = Shape
- Ctrl+Z = Undo, Ctrl+Y = Redo, Del = Delete
